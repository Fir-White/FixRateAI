Для рейтинга по нарядам или сравнения двух периодов заполни analysis. Укажите в results результат aggregate_work. Если проверяешь покрытие в режиме missing, включи analysis только если рейтинг был потерян. Прочие результаты, относящиеся к неизвестным пока объектам, опиши в projections. subjects для найденных при выполнении объектов оставь пустым.

group_by: equipment для оборудования, assignee для исполнителей, period для сравнения двух периодов. metric: overdue для числа просроченных незавершённых, unfinished для числа незавершённых, planned для числа запланированных работ в каждом периоде. limit — запрошенное число записей, windows — запрошенные календарные диапазоны ISO, as_of — явно указанная дата среза. source_text — дословный непрерывный фрагмент запроса о выборе или сравнении.

Для выбора задания используй group_by=task и метрику earliest_overdue (самый ранний нормативный срок просроченной работы) или missing_materials (недостающие материалы). При поиске оборудования без подтверждённого ТО используй equipment и without_service с точным диапазоном windows.

projections: equipment_details, overdue_tasks (названия и сроки), latest_maintenance (последний факт), maintenance_history (все принятые отчёты за период), active_regulations, maintenance_calendar, staff_details, staff_assignments (назначения сотрудников), task_details (карточка), task_materials (чек-лист, отчёт, фотографии, препятствия приёмке). history_months и calendar_months задают глубину в месяцах. compare обозначает просьбу сравнить отобранные записи. recommendations задаёт число запрошенных действий. Если нужны данные для каждой из выбранных записей, включи проекцию один раз. Сервер передаст найденные ID всем зависимым чтениям. Независимые запросы передавай в results или missing.
