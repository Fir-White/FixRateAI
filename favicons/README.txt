FIXRATE AI — FRESH GENERATED GLASS FAVICONS

These are exports from TWO newly generated 1254x1254 icon artworks, not from the tiny user screenshot or earlier screenshot-cropped favicon packages.

Versions:
- favicon-active.* — luminous cyan glass icon
- favicon-unavailable.* — grayscale glass icon

Each variant includes 16, 24, 32, 48, 64, 128, 192, 256, 512 and 1024 PNG files and a multi-resolution ICO.
Original 1254x1254 generated artworks are included under sources/.

Suggested usage in an HTML document:

For a known application-controlled offline/maintenance state, use the gray icon:
<link rel="icon" type="image/x-icon" href="/favicon-unavailable.ico">

NOTE: A web app cannot change the browser-generated favicon on a network error page when the app itself cannot load.
