## 1. Проект одной минутой

**FixRate AI** — помощник сметчика, не замена человеку.

Вход: фото дефекта + текст + характеристики здания.  
Выход: **черновик** ведомости объёмов работ (ВОР) и предварительная смета: работы, объёмы, материалы, расценки **со ссылкой на источник**, сумма.

Главный принцип: нейросеть распознаёт и подбирает кандидатов; **деньги считает детерминированный код**.  
Пока нет CV/NLP/RAG — те же шаги через **заглушки с тем же контрактом**.

MVP — несколько DEMO-сценариев, не «весь ФЕР страны». В git только демонстрационные расценки (`source_type=DEMO`), не сканы/выгрузки ФЕР/ТЕР.

Заказчик ТЗ: Уральский банк ПАО Сбербанк. Демо до фронта — **Swagger** (`/docs`).

## 4. Зафиксированные техрешения (не ломать без явного решения команды)

Подробности и мотивация — в `materials_for_ai/plan.md` §3. Кратко:

| Тема | Решение |
|---|---|
| Python | 3.12+ (в pyproject `>=3.12`) |
| API | FastAPI + Uvicorn, префикс бизнеса `/api/v1`, health снаружи: `GET /health` |
| ORM | SQLAlchemy 2.0 **sync** + psycopg3; роуты к БД — обычный `def`, не `async def` |
| Схема БД | только DDL архитектора в `db/`; **не** `Base.metadata.create_all()` как источник схемы; Alembic — только если архитектор так скажет |
| Auth к 29.10 | JWT email+password, роли operator / estimator / admin; не SSO |
| Фото | локальный диск за адаптером (`STORAGE_DIR`), не S3 до общего сервера |
| Оркестратор | библиотека **в том же процессе** FastAPI (Protocol); отдельный ML HTTP позже за тем же адаптером |
| Деньги | `Decimal` / `NUMERIC`, не `float` |
| Нет данных для расчёта | `needs_clarification` / ошибка, **не выдумывать** площади и цены |
| DEMO-расценки | вымышленные, явно помеченные; ФЕР/ТЕР целиком в git не класть |

**Три DEMO-сценария по умолчанию** (пока аналитик не заменил):  
`facade_crack`, `tile_chip`, `parking_leak`.

**Стык Яна ↔ Артём:** Артём отдаёт DTO результата пайплайна; Яна пишет `ai_runs` / `ai_results` / смету **в одной транзакции**. Формулы суммы — зона Артёма, не «примерно в роутере».

Подтвердить или заменить три пилотных дефекта (§ выше). Иначе stubs едут на DEMO-тройке.

## 8. Модель данных — только шпаргалка

Полные поля: `docs/database/specification.md` (18 таблиц). ER: `docs/database/erd.md`.

- UUID, `TIMESTAMPTZ`, деньги `NUMERIC`.
- Файлы не в БД — только `storage_key` + метаданные.
- Три разных статуса: заявка / AI run / смета — не одно поле на всё.
- Сметы версионируются: правка → новая строка `estimates`, `UNIQUE(request_id, version)`.
- Бизнес-правило: у заявки непустое описание **или** хотя бы одно фото.

Пока DDL нет — **модели SQLAlchemy не создавать «на глаз»**.

## 11. Definition of Done MVP к 29.10 (ориентир всей команды)
