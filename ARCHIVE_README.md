- `snapshots/kran_dev/` — previous `kran_dev` tip (`9bc7ce7`)
- `snapshots/ai_ml_service/` — previous `ai/ml-service` tip (`99e8314`)

The original Git histories are also reachable through the parent commits of this archive branch. These folders are preserved references, not active development roots.
