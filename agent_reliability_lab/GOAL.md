# Надёжность FixRate AI Agent v3

Подтвердить независимыми сквозными проверками точность, полноту и устойчивость Agent v3 для инженерных поручений и работы исполнителя. Использовать штатный FastAPI, LangGraph, локальную LLM, реальный RBAC и изолированный PostgreSQL. Сверять факты, расчёты, видимость, историю и записи с независимым oracle.

Приёмка требует как минимум 200 содержательно разных новых E2E-сценариев, минимум 95% успешных поддерживаемых поручений на независимом наборе и прохождение всех зафиксированных регрессий. Обязательны нулевые подтверждённые нарушения RBAC, несанкционированные и повторные записи, выдуманные критические UUID и факты. Проверить отказ источников, длинные диалоги, расчёты и сортировки, влияние на backend и frontend и исполнение на настоящей модели.

Лимит кампании — до 10 часов активной работы. Фиксировать факты по каждому прогону. Сохранять исходные изменения в worktree и использовать только изолированные тестовые данные.
