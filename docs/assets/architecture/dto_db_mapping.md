# Совместимый адрес исторического DTO/DB mapping

Этот файл сохраняет работоспособность относительных ссылок из исторических отчётов `docs/assets/database/`. Сам отчёт и исходный пакет аналитика не редактировались.

Исходный mapping был добавлен в коммите [418dbe6](https://github.com/krangras/FixRateAI/blob/418dbe6/docs/architecture/dto_db_mapping.md). Он относится к тому состоянию DTO и SQL и не является описанием всех последующих миграций.

Для текущей версии используйте:

- [Данные, история и соответствие сущностей таблицам](../../service/database.md).
- [Общие DTO обслуживания](../../../backend/app/schemas/maintenance.py).
- [Пользовательские команды управления](../../../backend/app/schemas/management.py).
- [ORM, репозитории и транзакции](../../../backend/app/db).
- [Последовательные SQL-миграции](../../../database/migrations).
- [Правила изменения контрактов](../../service/development.md#изменение-общего-контракта).

Фактический DDL определяется применённой цепочкой миграций; JSON Schema и DTO описывают границу API. Наличие исторического отчёта не заменяет проверку чистой БД, заполненного upgrade и актуального OpenAPI.
