## Локальный запуск и откат

Запускать из checkout нужного коммита `dev`: `python scripts/start_local.py --presentation` при подготовленном локальном CLIP cache, либо настроить cloud-профиль и запустить `python scripts/start_local.py --cloud-ai --presentation`. Команда без `--no-build` собирает образ из текущих исходников; существующий `--bundled-image` может содержать другую версию приложения и должен быть предварительно пересобран из нужного коммита. Аккаунты локального стенда создаются в `var/compose-local/accounts.txt`; секреты не коммитятся. Подробности, требования к моделям, запуск и остановка без удаления данных — в [инструкции](../service/runtime.md).

Для безопасного возврата использовать отдельный checkout исходного `dev` или `frontend_polished`, сохраняя текущие БД и файлы; не выполнять force-push и не сбрасывать чужие рабочие изменения. Состояние опубликованных веток проверяется через `git log` и актуальные удалённые указатели; этот документ фиксирует результаты до возможной последующей публикации.
