# Что исключено из активного маршрута

Новый запрос в dev получает `execution_engine=v4`. `service.agent_turn` вызывает единый цикл `tool_agent.run`; старый этап классификации не вызывается и не используется при ошибке модели. Возобновление старого `workflow` в профиле v4 не переключает движок: сервер предлагает написать новое сообщение.

| Из активного исполнения v4 исключено | Что используется вместо |
|---|---|
| Классификация и перехват реплик из `intents.py`, `dialogue_routing.py`, веток `orchestrator.py` | Нативное решение модели: ответ или инструменты |
| «Ближайший», «предыдущий», дата, выбор записи и фразы назначения из `maintenance_dialogue.py`, `maintenance_assignment.py`, `result_references.py` | Приватная история, фактические фильтры и результаты, локальный календарный контекст, серверный предпросмотр |
| Разбор цели, проверка намерения и семантический перепланировщик из `semantic_plan.py`, `request_coverage.py`, `operator_reviews.py`, `erp_operator.py`, `dynamic_dialogue.py` | Один агентный цикл, типизированная валидация каждого вызова и подтверждение изменения вне LLM |
| Формирование ответа по ключевым словам и текстовые формализованные поручения | Ответ модели по структуре фактов; только инфраструктурные отказы имеют фиксированный текст |
| Перехват сообщения с префиксом `Факты:` в старом React-композере | Префикс не обрабатывается в v4, текст целиком отправляется модели; продолжение старого поручения доступно только в прежнем профиле |
| Парсинг текста при подготовке карточки через `service.propose` | Эта ветка исполняется только для `v2`/`v3`; v4 получает аргументы из серверного расчёта |

Сохранены реестр возможностей API/MCP, авторизация ASGI, проверка сессии, ограничения назначений, безопасное хранилище, подтверждения и журнал. Строгая проверка UUID, диапазонов, статуса, JSON и технических форматов не интерпретирует речь. Буквальная подстрока в параметре поиска — фильтр данных, который выбирает модель, не решение о намерении.

Код v2/v3 сохранён для явного отката и чтения исторических диалогов/карточек. Незакоммиченные исходные изменения в этих файлах не удалялись. V4 не вызывает их для новой реплики; откат задаётся только при запуске сервера. Удаление исторического контракта и перенос старых незавершённых поручений в v4 не входят в этот срез.
