Здесь только обезличенные квитанции и синтетические эталоны. Не входят ключи, пароли, сессии, приватный runtime-профиль, дамп рабочей БД или файлы рабочего стенда.

| Файл | Что подтверждает |
| --- | --- |
| `frozen.json` | Базовый SHA, хеши локальных наложений и шаблона промпта |
| `static-evidence.json` | Хеши деревьев production SPA и 33 миграций |
| `predeclared.json`, `oracle.json`, `fixture-seal.json` | Реплики и ожидания, подготовленные до первого живого запроса; группировка, SQL-данные, источники тестовых JPEG и хеш дампа |
| `offline-http.json` | Пагинация, наблюдаемые HTTP-статусы и неизменность бизнеса |
| `offline-chrome.json` | Реальная SPA в Chrome, без отправки запроса модели |
| `offline-restore.json` | Восстановление дампа и совпадение отпечатков шести бизнес-таблиц |
| `profile.json`, `usage.jsonl` | Профиль живого прогона без ключа и журнал AI Tunnel: хеши системных сообщений, модель, токены и оценка расходов |
| `grades.json`, `main-observations.json`, `live-main-sql.json` | Ручная оценка, синтетические ответы и трассы, HTTP/SQL трёх подтверждений |
| `repeat-grades.json`, `measured-benchmark.json` | Повторы и все группировки основной выборки |
| `live-chrome-retry.json`, `live-chrome-retry-sql.json` | Реальное назначение и сдача в Chrome с точной моделью; финальный анализ не пройден |
| `offline-faults.json` | Проверка отказов инструментов и провайдера без сети |
| `local-profile.json`, `local-chrome.json` | Отдельный локальный запуск по запросу пользователя: на своей модели Ollama, не часть оценки DeepSeek |
