# Матрица требований и доказательств

Основания: ТЗ v1.0/v1.1, [MVP](../MVP_SCOPE.md), [источники](../service/planning-v1.1-gap.md). SHA-256 v1.1: `5b8678ac0b6590e0a66b966ee112cbfe98820fdda51836b675199abe94e9944a`. Частные исходники не публикуются. Наличие endpoint не означает успешной проверки, а серверная регрессия не закрывает пользовательскую приёмку.

Протоколы: **P** — 94 проверки `agent-audit-planning-baseline`; **S** — 12 сквозных сценариев `agent-audit-production-run`, настоящая БД/solver/подтверждения, преимущественно детерминированная маршрутизация; **L** — 7 сценариев `agent-audit-live-json-repair`, локальная модель, кроме допустимого раннего guard роли; **C** — 619 MCP/схема-проверок `agent-audit-evidence-after`; **A** — 73 проверки `agent-audit-scope-final`. Более поздние срезы — в [метриках](agent-quality-metrics.md).
