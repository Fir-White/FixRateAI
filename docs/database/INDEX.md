# Справочник PostgreSQL

Текущая модель, словарь, изменения 005–008 и порядок миграций описаны в [service/data](../service/data.md).

- [Спецификация](specification.md) — подробный каталог базовых 35 доменных таблиц.
- [Связи](relationships.md) — 72 FK базовой ER, ограничения и запросы для анализа отношений.
- [Машинный каталог](model_catalog.json) — используется ORM-тестами.
- [ER draw.io](erd.drawio) и [SVG](erd.svg) — исходная ER-модель; расширения runtime сверять с SQL.
- [DDL и миграции](../../database/migrations), [демонстрационные данные](../../database/demo/README.md), [SQL QA](../../database/qa/README.md).

Спецификация и ER сохраняют проектную базовую модель. Они не заявляют, что каждое последующее поле миграций 005–008 отражено в диаграмме; фактический DDL задают SQL.
