# Фото и сдача отчёта в v4 — план реализации

> Реализовать в текущем worktree. Проверки с записью — на одноразовой PostgreSQL и в Chrome на копии; после проверок обновляется только локальный стенд `:8766`, без изменений рабочего отчёта.

**Цель:** исполнитель присылает фотографии в чат наряда и одной карточкой подтверждает их прикрепление и условную передачу черновика инженеру. Если комплект неполный, фотографии сохраняются в черновике, а карточка перечисляет, чего не хватает. Приёмка остаётся за инженером.

**Границы:** MVP‑07/08/11, AT‑08…AT‑12, AT‑16, AN06/AN07. Использовать разрешения автора черновика, требования сохранённого регламента, нативный выбор инструмента v4 и штатное подтверждение. Без новых классификаторов, автоматического запуска работ, ввода показаний, изменения чек-листа или автоприёмки. Пользователь задаёт, какие снимки «до» и «после», если это не следует из его указаний; по пикселям время съёмки не определять.

**Команда:** `report_attach_and_submit` принимает `expected_revision`, `execution_id` и до четырёх привязок `{attachment_id, checklist_item_id, phase, view_key}`. Модель предлагает команду; сервер проверяет наряд и делает карточку из сохранённых названий файлов и пунктов. В диалоге с привязкой к заданию другой наряд запрещён. В общем чате наряд должен быть прочитан и однозначно выбран. Использовать только явно отправленные личные вложения этого чата, проверять их хеши и при подтверждении; не брать архивные фото из отчёта.

## 1. Предметная операция и подтверждение

**Файлы:** `backend/app/main.py`, `backend/app/schemas/assistant.py`, `backend/app/assistant/capabilities.py`, `backend/app/assistant/service.py`, `backend/app/assistant/action_outcomes.py`, `contracts/assistant-tools.json`, `tests/backend/test_v4_report_photos_submit.py`.

- [x] Реальный API/PostgreSQL проверяет два исхода: при полном комплекте отчёт на приёмке, при неполном — черновик с фото. До подтверждения нет записей; повтор и параллельные подтверждения не дублируют запись.
- [x] API-проверки отказов покрывают чужое вложение, неоднозначный наряд, отозванное назначение и сессию, устаревшую ревизию, прямой вызов, повреждённый файл и неверные фазы. Браузерный контроль записи выполняется только в копии.
- [x] Переиспользованы `editable`, проверки фото и сдачи. При отказе файлы не сохраняются; некондиционный комплект сохраняется только как черновик. Сохранены обычные статусы, уведомления, аудит и фотоанализ.
- [x] Зарегистрированы транспорт и capability; команда исполняется только из подтверждённой карточки. Отчёт перечитывается для сверки результата. Контракт обновлён без расширения ролей.

## 2. Штатная карточка в чате v4

**Файлы:** `backend/app/assistant/tool_agent_tools.py`, `backend/app/assistant/tool_agent.py`, `backend/app/assistant/prompts/tool-agent.md`, `frontend/src/features/assistant/ActionCard.tsx`, `docs/service/user-experience.md`, `tests/backend/test_v4_report_photos_submit.py`, профильный тест карточки в `tests/web/unit/`.

- [x] API-тест отправляет реальное вложение в личный чат. Модель-заглушка вызывает нативный инструмент; до клика наряд не меняется. Неопределённые фазы не создают карточку, уточнение к предыдущему сообщению работает без повторной загрузки.
- [x] Карточка исполнителя показывает наряд, попытку, файл, пункт, фазу и ракурс. После подтверждения видны статус, недостающие данные и ссылка на задание.
- [x] Chrome на desktop/mobile и изолированная БД подтвердили условное сохранение после одного нажатия и восстановление карточки. API и SQL независимо сверили статус и количество фото. Повторная доставка команды проверена; обрыв сети в момент подтверждения отдельно не имитировался.

## 3. Рабочее пространство чата

Убрать из чата контекстную строку даты и роли, историю действий и управление диалогами разместить в одном ряду. Верхнюю навигацию приложения не менять. Вставка из буфера добавляет фото в черновик, не отправляя его. Миниатюры открывают защищённый просмотр до и после отправки; фото из отчёта имеют отдельную подпись. Сохраняются обычная вставка текста, XLSX, история, Back/Forward и клавиатурный выход из просмотра.
