| Состав после начала/при доработке | Отдельный безопасный процесс переназначения и история; существующая отмена ограничена работой до начала и отчёта |
| Несколько объектов и ролей | Переключение контекста в одной веб-сессии; работа прав и site scope должна сохраняться |
| Многооперационные наряды | UI и фотопоток с однозначным контекстом каждого оборудования/пункта; сейчас действует ограниченный сценарий |
| Реальные данные ML и нормы | Подтверждённые единицы норм/длительности, target потребности в ТО, временное разбиение, baseline и оценка RF/CV на реальных размеченных данных |
| Эксплуатация и интеграции | Backup/restore БД, фото и моделей, мониторинг, лимиты/политика регистрации, замеры ресурсов; внешние кадровые/ERP/телеметрические источники и универсальный импорт Excel |
