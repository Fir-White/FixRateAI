## Совместимость

1. На отдельной PostgreSQL прогнать миграции и проверку схем, затем backend и корпуса. Для сборки с изменённым запуском применить `027_assistant_turn_claim.sql` перед стартом приложения.
2. `assistant_turns.workflow` продолжает принимать прежние JSON записи. V2 добавляет поля без пересоздания истории или смены версий ранее сохранённых поручений. Новая колонка захвата допускает пустое значение у старых записей.
3. Запрос истории с датами и обычный список задач сохраняют прежние значения параметров по умолчанию. Новые фильтры и `latest_only` включаются явно. Контракты каталога и матрицы приёмки пересобраны штатными скриптами.
4. При откате приложения дополнительная колонка остаётся допустимой. Операции на действующих подтверждениях и поручениях требуют сохранения тех же idempotency key и корневого ID.

## Воспроизведение

Нативная проверка создаёт временный PostgreSQL, запускает миграции и использует учебные данные. Зависимости планировщика берутся из `requirements-solver.txt`. На Windows передайте каталог установленных бинарников PostgreSQL.

```powershell
python -B scripts/verify.py --pg-bin 'C:/Program Files/PostgreSQL/18/bin' --agent-only --pytest-target tests/backend/test_assistant_architecture_v2.py tests/backend/test_assistant_v2_benchmark.py
python -B scripts/verify_agent_local.py --live --model qwen3.5:4b-q4_K_M --pytest-target tests/backend/test_assistant_v2_benchmark.py tests/backend/test_assistant_architecture_v2.py::test_live_nc01
python -B scripts/assistant_capabilities.py
python -B scripts/assistant_acceptance_matrix.py
```

[Корпус из 60 запросов](../../tests/fixtures/assistant-architecture-v2.tsv) включает инженерные чтения, поиск, раздельные когорты нарядов, выбор даты отчёта, текущую редакцию регламента, календарный расчёт, восстановление, подтверждения и отрицательные сценарии. Проверки задания сравнивают результат с независимо выбранными связями в PostgreSQL. Провайдер со сценарным намерением проверяет механизм на реальном HTTP. Живой профиль использует закреплённый Qwen за исключением контролируемых отказов и некоторых переходов сохранённого состояния. Для каждого случая сохраняются ответ, трасса и категории `SUPPORTED`, `UNSUPPORTED`, `CONTRADICTED`, `UNVERIFIABLE`.

Результаты, известные ограничения и отдельные прогоны находятся в `reports/assistant-architecture-v2/`. Критерии исторических A/B и разговорного корпуса сохранены. Частичные повторы приводятся с указанием проверенной версии. [Контракт архитектуры](../architecture/assistant-architecture-v2.md)
