# Документация FixRateAI

Это единственный комплект описания проекта. В модулях нет отдельных README и копий этих документов.

- [Архитектура](ARCHITECTURE.md) — назначение, возможности, движение данных, исходные требования, реализация и границы.
- [Узлы сервиса](service/INDEX.md) — запуск, backend, веб, планирование, PostgreSQL, ML/CV, проверки и порядок разработки/интеграции.
- [План](PLAN.md) — запланировано, в работе, готово.
- [ADR](decisions/INDEX.md) — принятые решения по дате и теме и шаблон новой записи.
- [Motion System 1.0](ui/motion-system.md) — токены, появление, переходы и обратная связь интерфейса.

Машинные контракты, исходники диаграмм, fixtures, SQL и протоколы запусков сохраняются по своим рабочим путям; ссылки на них находятся в описаниях соответствующих узлов.

[Проверка охвата файлов](REVIEWED_FILES.txt) фиксирует исходный срез, области, способ просмотра, хеши и перенос прежних Markdown. Это снимок проверки, а не ещё одно описание системы.

Структура синхронизирована с `origin/dev` `7d0f625` для текущей frontend-ветки с локальными изменениями. Описание входа, регистрации, Aurora и favicon находится в [web](service/web.md#вход-и-фон-aurora); [протокол переноса и проверок](service/verification.md#01112026-приведение-документации-frontend-к-структуре-dev) отделён от исторических запусков.
