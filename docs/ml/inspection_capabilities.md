# Фотоанализ: возможности и проверка

| Случай | Текущий результат | Граница |
|---|---|---|
| Отсутствует CLIP или веса | `unavailable`, `MODEL_NOT_READY` | Эвристика не подменяет модель |
| Отсутствует пара, разное `view_key`, плохое качество | `uncertain` | Совпадающий `view_key` сам по себе не доказывает одинаковый ракурс или объект |
| Визуальный пункт при доступном CLIP | Сопоставление двух текстовых описаний чистой/грязной поверхности | Не доказательство качества ТО; порог и скоры не калиброваны, вывод проверяет человек |
| Скрытые операции, 1.5 и 1.6 | `not_verifiable` | Фото не подтверждает настройку, точность, внутренние детали или выпуск воздуха |
| Ошибка обработки | `failed` | Результат не является решением о приёмке |

Тестовые изображения в репозитории синтетические. **Проверка 2–3 пар реальных фотографий не проведена**: в репозитории нет соответствующих разрешённых пар, а установленные зависимости и локальные веса CLIP не подтверждены. Нет подтверждения качества на оборудовании заказчика. Для завершения нужны разрешённые пары, ручная разметка сопоставимости и видимых изменений, фиксированные веса/ревизия, результаты по каждой паре и ресурсы инференса. Статусы не подтверждают выполнение работы; решение принимает контролёр. `review_photos` вызывается backend через `PhotoReviewRequest` и загрузчик байтов; реально подключённого backend-потока приёмки в текущей ветке нет.
