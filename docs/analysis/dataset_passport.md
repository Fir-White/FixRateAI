## 2. Категоризация источников и типов происхождения

В архитектуре FixRate AI введено строгое разделение происхождения визуальных данных:

| Тип происхождения (`origin_type`) | Определение | Допустимое применение | Присутствие в проде / пилоте |
| :--- | :--- | :--- | :---: |
| **`real_customer`** | Необработанные фотографии реального оборудования с пилотных объектов заказчика, снятые выездными техниками/инженерами с верифицированным контекстом ТО. | Обучение, независимая валидация точности, калибровка порогов, бенчмаркинг моделей. | **Целевой пилотный стандарт** |
| **`demo`** | Кадры из открытых фотостоков (Unsplash, Pexels) или открытых обучающих материалов производителей, иллюстрирующие общий вид оборудования. | Демонстрационные стенды, UI-скриншоты, контрактные тесты парсинга DTO. | Запрещено выдавать за результаты пилота |
| **`synthetic_edited`** | Фотографии реального оборудования, в которые внесены локальные графические правки (программный поворот стрелки манометра, ретушь дефектов/водяных знаков). | Тестирование реакции детектора на локальные изменения признаков при неизменном ракурсе. | Запрещено выдавать за результаты пилота |
| **`synthetic_augmented`** | Изображения с программно наложенными дефектами фотосъёмки (Motion Blur, искусственный блик вспышки Lens Flare, шум). | Юнит-тестирование модуля отбраковки некачественных кадров (`ImageQualityGuard`). | Запрещено выдавать за результаты пилота |

## 4. Почему имеющийся корпус недостаточен для пилота

1. **Отсутствие статистической мощности:** 6 позитивных и 3 негативных примера не позволяют рассчитать доверительные интервалы метрик (Precision, Recall, F1, Accuracy) или калибровать пороги QualityGuard.
2. **Нулевой охват оборудования СВиК:** В фикстурах представлены только элементы тепловых пунктов (манометры, теплосчетчики, коллекторы, щиты АВР). Системы вентиляции и кондиционирования (приточные установки, фильтры карманного типа, вентиляторы, фанкойлы, чиллеры) полностью отсутствуют.
3. **Синтетическая природа критических кейсов:**
   * В `CASE-01` стрелка повернута графическим редактором — шкала и прибор в реальности не находились под рабочим давлением.
   * В `CASE-05` трещина затерта ретушью — физический прибор не ремонтировался и метрологическая поверка не проводилась.
   * В `CASE-06` нет строгой уверенности в тождестве узла до и после (стоп-кадры из стороннего учебного видео).
4. **Отсутствие естественных эксплуатационных вариаций:** нет снимков при пыли, слабом освещении подвалов, разных углах съемки с рук технического персонала.

## 5. Юридический статус и авторские права

1. **Исходные фотографии стоков (`CASE-01`):** Распространяются под лицензиями Creative Commons Zero (CC0) / Public Domain. Допускают использование в учебных и демонстрационных стендах.
2. **Материалы каталогов и учебных пособий (`CASE-02..CASE-06`):** Использованы по принципу Fair Use исключительно для некоммерческих учебных и исследовательских целей студенческого проекта (УрФУ). Прямых лицензионных договоров с правообладателями нет. Публикация в коммерческих продуктах запрещена.
3. **Собственные модификации команды (`CASE-01_before`, `CASE-03_before`, `CASE-05_after`, `neg_01`, `neg_02`):** Права принадлежат команде FixRate AI.
4. **Будущие реальные фото пилота (`real_customer`):** Должны передаваться по акту приёма-передачи с согласием заказчика на обработку технической информации без передачи прав третьим лицам.

* **`frai-cv-v0.1.0-demo`** (текущая): демонстрационные фикстуры аналитика (14 файлов, хеши зафиксированы).
