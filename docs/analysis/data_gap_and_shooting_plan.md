## ЧАСТЬ II. Согласованный план полевой досъёмки (Pilot Photo Collection Plan)

Для разблокировки направления ML/CV утверждается следующий полевой протокол сбора данных силами выездных инженеров и техников.

### 1. Общие правила фотофиксации на объекте

1. **Парность съёмки («До» и «После»):**
   * Каждый технологический процесс фиксируется строго двумя кадрами: снимок **«До начала работ»** и снимок **«После завершения работ»**.
   * Не допускается съёмка кадра «После» без предварительного кадра «До».
2. **Стабильность ракурса (Viewpoint Consistency):**
   * Камера смартфона должна располагаться строго фронтально к прибору/агрегату (угол отклонения от перпендикуляра не более 15°).
   * Дистанция съемки фиксированная:
     * Для приборов КИПиА (манометры, термометры, дисплеи счетчиков): **0.3–0.5 м** (макро).
     * Для узлов и агрегатов (фильтры, клапаны, насосы): **0.7–1.2 м** (средний план).
     * Для шкафов управления и вентустановок: **1.5–2.5 м** (общий план установки).
3. **Требования к освещению:**
   * Не снимать в полной темноте (минимальная освещенность рабочей зоны — не менее 50 люкс).
   * **Запрет прямой вспышки на стеклянные циферблаты и зеркальный металл:** прямая фотовспышка создает белый ослепляющий блик, препятствующий считыванию показаний и проверке чистоты. Использовать рассеянный боковой свет налобного или переносного фонаря.
4. **Обязательная привязка к идентификаторам оборудования:**
   * В кадре (или на отдельном дополнительном снимке маркировки) должен четко читаться инвентарный номер, маркировочная бирка или заводской шильдик оборудования.

### 2. Обязательный состав контрольных сценариев досъёмки

План досъёмки обязан содержать не только идеальные позитивные примеры, но и сложные пограничные и отрицательные ситуации:

#### А. Позитивные пары с видимыми изменениями (`visible_change`)
* Очистка воздушного фильтра вентустановки (грязный темный фильтр $\rightarrow$ чистый новый фильтр).
* Очистка сетчатого грязевика ИТП (сетка в слое шлама $\rightarrow$ промытая чистая сетка).
* Устранение течи/подтекания сальника (следы влаги/капель $\rightarrow$ сухой узел после протяжки).
* Смена индикации щита управления (сигнал аварии/останова $\rightarrow$ рабочий режим «Пуск»).

#### Б. Контрольные пары «без изменений» (`no_visible_change` / False Positive control)
* Снимок оборудования «До» и повторный снимок того же оборудования через 5 минут без проведения работ.  
  *Цель:* Модель обязана вернуть вердикт `no_visible_change` / `uncertain` и не выдумывать ложное выполнение работ.

#### В. Пары с разным оборудованием одного типа (`mismatch_equipment`)
* Снимок манометра контура №1 «До» и снимок соседнего манометра контура №2 того же типа «После».  
  *Цель:* Проверка способности классификатора выявлять подмену оборудования.

#### Г. Отрицательные примеры брака съёмки (Negative Defect Cases)
* **Смазанный кадр (`blur`):** снимок с руки на ходу или при резком движении.
* **Бликующий кадр (`glare`):** снимок циферблата счетчика со вспышкой «в лоб».
* **Недостаток света (`underexposed`):** снимок в темной венткамере без подсветки.
* **Срыв ракурса (`viewpoint_mismatch`):** кадр «До» снят сверху, кадр «После» снят сбоку под острым углом.

### 4. Порядок передачи и оформления данных

1. Инженер выгружает фотографии в защищённый каталог обмена (защищённый S3 / выделенная папка инженера).
2. К каждой серии снимков прикладывается заполненная таблица метаданных (CSV/XLSX):
   * `session_id`: идентификатор сессии съемки;
   * `object_id`: наименование и адрес объекта пилота;
   * `equipment_id`: инвентарный номер и марка агрегата;
   * `operation_id`: код технологической операции по регламенту;
   * `phase`: `before` / `after` / `negative_blur` / `negative_glare`;
   * `technician_name`: ФИО ответственного техника (для журнала сбора, в Git не попадает);
   * `actual_work_done`: описание реально выполненного действия.
3. Перед импортом в систему фото проходят автоматическую санитизацию по стандарту TL04 (очистка EXIF, удаление PII, генерация SHA-256).
4. На основании проверенных файлов формируется официальный манифест следующей версии: `frai-cv-v1.0.0-pilot`.
