## 1. Проверка функционирования (Операция 1.3)
1. Проверка индикации на передней панели: светодиод «Сеть / Питание» — непрерывное зеленое свечение.
2. Светосигнальная лампа «Авария» должна быть погашена.
3. Переключатель режима работы насосов должен находиться в положении «Авто».
4. Внутренняя коммутация щита и проверка автоматических выключателей является скрытой операцией (`not_verifiable`), не подлежащей автоматической приемке по внешней фотографии шкафа.
