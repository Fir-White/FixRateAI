# Инструкция по снятию архивных и текущих параметров тепловычислителя ВКТ-7

## 1. Назначение
Инструкция регламентирует процесс считывания показаний потребления тепловой энергии и объема теплоносителя с жидкокристаллического дисплея вычислителя ВКТ-7.

## 2. Порядок фиксации (Операция 1.2)
* Основные единицы измерения: тепловая энергия — **Гкал** (`Gcal`), накопленный объем — **м³** (`m3`).
* Фотография должна четко отображать сегменты ЖК-дисплея без стробирования (эффекта мерцания подсветки).
* Цифровые показания, считанные OCR-модулем, заносятся в черновик протокола и подлежат ручной сверке главным инженером.
