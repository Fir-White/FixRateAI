## Целевая структура и основания

По решению владельца сохраняются четыре имени: `main`, `dev`, `kran_dev`, `archive/legacy-ai-estimator`. Последняя остаётся архивом прежнего продукта; её содержимое и история не добавляются в рабочее приложение. Остальные имена удаляются после проверки источников и сохранения истории. Это новое решение заменяет прежнее требование сохранять все исходные имена GitVerse; датированные протоколы переноса остаются историческими.

`dev` — общая интеграция, `kran_dev` — рабочая ветка владельца. `main` сохраняется отдельно: GitHub использует её по умолчанию, но её commit `892b23a` относится к 7 ноября. В рамках очистки main не обновляется и рабочие изменения в её worktree не перезаписываются. Изменение default branch и выпуск новой версии main являются отдельными действиями.

## Удаление и синхронизация

Штатная двусторонняя синхронизация GitHub/GitVerse восстанавливает имя, удалённое только с одной стороны. Первоначально планировалась временная приостановка, но автоматическая проверка разрешений отклонила отключение GitHub Actions как отдельное операционное изменение без явного разрешения. Workflow не отключается, его настройки и состояние не меняются.

Применяется вариант без изменения автоматизации: сначала публикуются сохранённые истории, проверяется завершение текущих sync-запусков, затем проверенные имена удаляются на обеих площадках в одном коротком этапе. Для каждого ref используется точный ожидаемый SHA, push атомарен внутри хостинга. Между хостингами общей транзакции нет, поэтому возможное восстановление имени синхронизацией проверяется отдельно; повтор допустим только для того же проверенного SHA, новые коммиты не удаляются.

После удаления проверяются ровно четыре имени и совпадающие SHA на обоих хостингах, сохранность archive/main и файлов worktree, чистота текущего checkout. Итог проверяется также после автоматического sync-запуска. Синхронизация остаётся в исходном состоянии. Сетевые журналы и проверки сохраняются локально в `reports/`; незавершённая попытка не считается подтверждением удаления.
