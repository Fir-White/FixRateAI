# Автоматический анализ отправленного фотоотчёта

Дата: 06.11.2026. Статус: принято по запросу владельца.

Исполнитель сдаёт замороженный отчёт с парой before/after. AI запускается после commit без запроса и предварительного подтверждения инженера. Новая попытка получает durable-маркер в execution_context; существующий фоновый worker и scheduler выполняют анализ идемпотентно и восстанавливают прерванный запуск. Старые отчёты без маркера не обрабатываются массово.

Наличие методики не используется как дополнительный gate запуска; обязательные нормативы и доказательства по-прежнему проверяются на своих этапах. Результат относится к конкретной попытке и сохраняется в ai_quality_checks, ошибка не отменяет сдачу. UI показывает pending/результат/ошибку и обновляется автоматически. Повтор после ошибки доступен инженеру.

Человеческое подтверждение сопоставимости не имитируется: при автоматическом вызове оно false. Модель анализирует реальные фото, консервативная оценка может оставаться uncertain/manual_review. Это уточняет порядок запуска из [предыдущего решения](2026-11-04--local-vision-review.md), сохраняя требования к положительному подтверждению и человеческой приёмке. AI не закрывает работу самостоятельно.

Проверки: реальный HTTP/PostgreSQL/хранилище с явно указанным ML contract stub для повторов/ошибок/recovery; браузерный сценарий сдачи без инженерного POST; UI polling до результата и отмена опроса. Это не объявляется новым облачным инференсом.
