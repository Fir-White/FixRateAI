# Скрытые операции не проверяются по фото

- ID: `ADR-2026-10-28-hidden-operations`
- Дата: 2026-10-28
- Статус: принято (исходный `APPROVED`)
- Задача: —; сохранены прежние идентификаторы ADR-006.

## Исходное решение ADR-006: Безусловный вердикт not_verifiable для скрытых операций

* **Контекст:** В регламенте есть операции 1.5 («Проверка точности приборов») и 1.6 («Выпуск воздуха из системы отопления»). Работники могут прикрепить фото манометра или крана Маевского.
* **Решение:** Модуль анализа фото проверяет атрибут `visual_verifiability` в чек-листе. Если значение равно `"not_verifiable"`, модуль **принудительно выставляет вердикт `not_verifiable`**, минуя оценку нейросетью.
* **Последствия:** Устранение риска ложного одобрения: фото циферблата не подтверждает точность поверки прибора, а фото крана не доказывает отсутствие воздушной пробки в контуре.
