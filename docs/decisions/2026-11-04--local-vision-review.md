# Локальный содержательный разбор фотоотчёта

Дата: 04.11.2026. Статус: принято для локального профиля.

CLIP clean/dirty delta не описывает повреждения прибора и не обосновывает качество выполнения ТО. Его технический score нельзя выдавать за содержательное инженерное заключение. Пользователь выбрал полностью локальную обработку.

Принято использовать Qwen3.5 4B через закреплённую Ollama в отдельном GPU-контейнере. Первичная установка скачивает веса; рабочий контейнер имеет только internal network, cloud отключён, внешние endpoints/redirects/proxies запрещены клиентом. Точные версии, подготовка и исполнение описаны в [ML](../service/ml.md#подробный-локальный-разбор-фото) и [запуске](../service/runtime.md#локальная-vision-модель-для-фотоотчёта).

Каждое фото сначала описывается отдельно без текста задания, затем модель сравнивает пару с чек-листом. Ответ валидируется общей схемой; исходные отдельные описания не подменяются итоговым сравнением. При отсутствии фактов либо сбое выдаётся uncertain/failed/unavailable; успешного CLIP fallback нет. Прежние результаты сохраняются без переписывания истории. Подробные поля добавлены в JSON findings, SQL-миграция не требуется.

Предложения модели могут содержать ошибки. Фото не подтверждают скрытые/метрологические действия или безопасность. Модель не закрывает задание и не заменяет ручную приёмку. Положительное визуальное изменение требует сопоставимого объекта/ракурса, явного описания наблюдаемого изменения и отдельного человеческого подтверждения сопоставимости. Точность на заказчике этим решением не заявляется.
