| 2026-10-28 | [ADR-2026-10-28-hidden-operations](2026-10-28--hidden-operations.md) | Скрытые операции не проверяются по фото | Принято |

Новое решение создаётся по [шаблону](ADR-TEMPLATE.md) с именем `YYYY-MM-DD--topic.md` и ID `ADR-YYYY-MM-DD-topic`. Ссылку на задачу добавляют только при наличии настоящей задачи. Реализация решения сама по себе не доказывает достижение ожидаемых метрик.

## Применение записей

Для перенесённых записей сохранение решения не является новой оценкой качества. Числовые ожидания раннего проекта не считаются результатами замеров. Текущие параметры, ограничения и связи с кодом — в [вебе](../service/web.md), [ML/CV](../service/ml.md), [API](../service/backend.md) и [оркестраторе](../service/planning.md). Каждая новая запись ссылается на собственные доказательства.
