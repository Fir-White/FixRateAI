# Быстрый запуск FixRate AI

**Требования:** Windows 11 x64 с Docker Desktop/WSL2 или Linux amd64 с Docker Engine; Docker Compose ≥2.24, рекомендуются 8 ГБ ОЗУ и 10 ГБ диска. Python, Node.js и внешний PostgreSQL не требуются.

Используйте архив `FixRateAI-QuickStart-X.Y.Z.zip` из разрешённого релиза. `compose.yaml` и `images.env` в нём задают проверенные образы; исходный каталог `quick_start/` сам по себе не содержит образов. До публикации используйте исходную сборку или локальные образы, проверенные отдельно.

1. Сверьте SHA‑256 архива с внешним `SHA256SUMS`, распакуйте его в отдельный каталог. Внутренний `SHA256SUMS` проверяет каждый файл комплекта (`sha256sum -c SHA256SUMS` в Linux; в Windows — сверка `Get-FileHash -Algorithm SHA256`).
2. Скопируйте `.env.example` в `.env`. Назначьте уникальное `FIXRATE_PROJECT` для новой установки, чтобы не подключить тома другого проекта. Установите `POSTGRES_PASSWORD` — уникальную случайную строку только из шестнадцатеричных символов (минимум 32). Сгенерируйте отдельный случайный ключ первичной настройки (минимум 32 символа) и запишите **только** его SHA‑256 в `FIXRATE_BOOTSTRAP_TOKEN_SHA256`. Не вставляйте секреты в командную строку; сохраните ключ в менеджере паролей. Для автоматической генерации воспользуйтесь установщиком из того же релиза.
3. Запустите из распакованного каталога:

   ```console
   docker compose --env-file images.env --env-file .env config --quiet
   docker compose --env-file images.env --env-file .env up -d --wait
   docker compose --env-file images.env --env-file .env ps
   ```

4. Откройте `http://127.0.0.1:8080/setup` и введите исходный ключ в форме настройки, не в адресной строке. Создайте первый аккаунт, затем войдите через `/login`. Развёртывание не подмешивает учебные данные и не скачивает модели. Не публикуйте учётные записи и ключ настройки.

## Эксплуатация

Во всех командах используйте те же `--env-file images.env --env-file .env` и каталог проекта.

| Задача | Действие |
|---|---|
| Проверить работу | `docker compose … ps`; при необходимости `docker compose … exec api python scripts/release_runtime.py doctor` |
| Найти причину сбоя | `docker compose … logs --tail=100 migrate api web`; не публикуйте `.env`, `config` без `--quiet` и необработанные логи |
| Остановить безопасно | `docker compose … stop`; повторный `up -d --wait` использует те же тома. Не используйте `down -v` |
| Обновить или откатить | Предпочтительно через установщик: резервная копия БД и файлов, проверка совместимости по манифесту и обновление всего комплекта. Для отката храните прежний комплект и снимок, сделанный **до** миграций; не понижайте схему вручную |
| Резервное копирование | Нужна согласованная копия PostgreSQL и `files`; используйте `backup`/`restore` официального установщика или [регламент установки](https://github.com/Fir-White/FixRateAI/blob/main/docs/service/installation.md). Восстановление сначала проверяется в отдельном проекте |
| Внешний домен | Только по отдельному разрешению: DNS, HTTPS на входном шлюзе, `COOKIE_SECURE=true`, ключ настройки выключен после инициализации. Не открывайте PostgreSQL и API напрямую. Публичный платный AI-режим требует отдельного лимита и допуска |

Если порт 8080 занят, выберите другой `FIXRATE_PORT`. Если не скачиваются образы, проверьте наличие официального релиза, доступность реестра и поддержку `linux/amd64`. Если `migrate` не завершился успешно, проверьте его журнал и параметры подключения вместо повторного удаления БД.

Для закрытого облачного стенда (Compose ≥2.24.4) добавьте `-f compose.yaml -f compose.cloud.yaml` и задайте `AITUNNEL_API_KEY` в приватном окружении. Override заменяет веб-порты одним loopback-портом, даже если в `.env` указан внешний bind. Не подключайте внешний шлюз. Без override платный провайдер отключён.
