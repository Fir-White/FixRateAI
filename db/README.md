# db/ — каноническая схема БД

Сюда архитектор БД кладёт **официальный SQL** (например, `001_init.sql`). Это единственный источник схемы.

Правила:
- Backend **не** создаёт таблицы через `Base.metadata.create_all()`.
- Модели SQLAlchemy (карточка 2) срисовываются 1-в-1 с этого SQL и `docs/database/specification.md`.
- Alembic подключаем только если архитектор так договорился; первая ревизия повторяет уже существующий SQL.

Пока SQL не передан, папка пуста — это ожидаемо (карточка 2 BLOCKED).
