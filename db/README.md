# Каноническая схема БД

Сюда кладётся **официальный SQL / миграции архитектора** (например `001_init.sql`).

Пока файла нет:

- backend карточки 1 **не** создаёт таблицы через `Base.metadata.create_all()`;
- Alembic с «выдуманной» первой ревизией не заводится;
- `docker-compose.yml` поднимает пустой Postgres с расширением pgvector.

Когда SQL появится:

1. Положите файл в эту папку.
2. Примените к пустой БД (команда в корневом или backend README).
3. Модели SQLAlchemy сверяйте 1-в-1 с DDL и `docs/database/specification.md`.
