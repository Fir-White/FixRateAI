# Этапы

1. Снять исходный срез и повторить пользовательские регрессии через API с PostgreSQL и Qwen.
2. Заморозить тестовые контракты и добавить SQL-oracle, синтетические данные и сохраняемую оценку новых поручений.
3. Воспроизводить первые расхождения в порядке риска. Для каждого исправления повторять исходный случай, близкие случаи и обязательные регрессии.
4. Расширить сценарии по четырём ролям, операциям с подтверждением, долгим диалогам, отказам и контексту. Отдельно измерить контрольный корпус, вариативность модели и задержки.
5. Повторить backend и браузерные проверки на принимаемом срезе. Сохранить результаты и сверить каждый критерий с измерениями.

Исходные архитектурные контракты описаны в [Agent v3](../../docs/architecture/assistant-architecture-v3.md). Историю и следующую незавершённую операцию хранит [PROGRESS.md](PROGRESS.md). Приватные сырые артефакты сохраняются в `reports/agent-reliability-v3-*`, под существующим Git ignore.
